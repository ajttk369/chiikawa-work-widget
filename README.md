# 먼작귀 업무시간 위젯

Windows에서 별도 창으로 실행되는 오프라인 Electron 위젯과, 설치 없이 링크로 사용하는 웹 버전을 제공합니다. 세 캐릭터가 걷고 쉬며, 설정한 일정에 맞춰 점심을 먹고 퇴근 인사를 합니다.

## 웹 실행과 Vercel 배포

로컬 웹 화면은 다음 명령으로 엽니다. 기본 주소는 `http://127.0.0.1:5178`이고, 사용 중인 포트가 있으면 출력된 다음 포트를 사용합니다.

```powershell
cd "C:\Users\DYU\Desktop\종안\포폴모음\먼작귀"
npm.cmd run web
```

웹에서도 업무시간·근무 요일·점심 메뉴·캐릭터 반응·미리보기·미니 모드·배경·불투명도·휴식 알림을 사용할 수 있습니다. 설정과 최근 60개 근무 날짜의 기록은 방문자 브라우저의 `localStorage`에 저장됩니다. 다른 사용자나 기기에 공유되지 않으며, 사이트 데이터 삭제 또는 비공개 창 종료 시 사라질 수 있습니다. 같은 브라우저의 다른 탭에서 변경한 설정은 반영됩니다. 웹과 Windows 앱의 설정은 서로 별개입니다.

웹의 SET은 페이지 안의 설정 대화상자를 열고, 저장하거나 닫아도 위젯이 유지됩니다. 항상 위에 표시·클릭 통과·트레이·앱 종료는 웹에 추가하지 않았으며 관련 버튼과 설정은 숨깁니다. 데스크톱에서는 장면 모서리의 브라우저 크기 조절 핸들로 표시 크기를 변경할 수 있습니다. 웹 휴식 알림과 캐릭터 동작은 화면이 열린 동안 제공하며, 숨겨진 탭이나 닫힌 브라우저에서 시스템 알림·백그라운드 실행을 보장하지 않습니다.

GitHub에 이 폴더를 업로드한 뒤 Vercel에서 저장소를 Import합니다. 별도 로그인·API 키·환경변수는 필요하지 않습니다.

- Root Directory: 이 프로젝트가 저장소 루트라면 기본값. 전체 모음을 올린 경우 `먼작귀`.
- Framework Preset: `Other`.
- Install Command: `npm ci --omit=dev --ignore-scripts`.
- Build Command: `node scripts/export-web.cjs`.
- Output Directory: `dist`.

프로젝트 루트의 `vercel.json`에 위 설정과 보안 헤더가 포함되어 있습니다. 설치 시 Electron 개발 의존성과 설치 스크립트를 제외하고, 웹 화면·공용 일정 모듈·필요한 PNG·Lucide만 `dist`에 복사합니다. 메인 프로세스, 개인 설정 파일, 전체 `node_modules`는 웹 배포물에 포함하지 않습니다. `dist`는 Git 업로드 대상이 아니며 Vercel 배포 단계에서 생성됩니다.

일정 계산은 `schedule.js`를 공유하고 `schedule.cjs`는 기존 Electron 코드용 진입점으로 유지합니다. `web/host.js`가 브라우저 저장·상태를 관리하고, `renderer/web-bridge.js`가 같은 캐릭터 화면과 설정 화면을 연결합니다. 웹은 동일 출처 프레임만 사용하며 외부 통신·광고·추적을 추가하지 않았습니다.

## Windows 설치 파일

치이카와 얼굴 PNG와 여러 해상도를 담은 ICO를 앱·설정 창·트레이·실행 파일·설치 프로그램에 사용합니다. 웹 파비콘과 터치 아이콘도 같은 그림을 사용합니다. 아이콘 전용 원본은 `assets/chiikawa-source.png`, 변환 스크립트는 `scripts/prepare-icons.ps1`입니다. 공식 캐릭터 배포 자료가 아니라 기존 캐릭터 그림을 참고해 생성한 이미지입니다.

설치 파일 제작은 사용자가 아래 명령으로 실행합니다. 첫 실행은 `electron-builder` 26.x와 필요한 제작 도구를 내려받습니다.

```powershell
cd "C:\Users\DYU\Desktop\종안\포폴모음\먼작귀"
npm.cmd run dist:win
```

`electron-builder.json`의 아이콘 설정으로 Windows x64 설치 파일을 `dist/desktop/chiikawa-work-widget-setup-1.0.1-x64.exe`에 생성합니다. 앱과 설치 프로그램의 아이콘을 바꾸고 기존 설치와 같은 App ID를 유지합니다. 최신 요청에 따라 바탕화면·시작 메뉴 바로가기를 생성하며 Windows 로그인 시 자동 실행은 등록하지 않습니다. 앱 기본 기능에 필요한 파일과 운영 의존성만 포함하고 소스 원본 아이콘·웹 호스트·개발 로그·개인 설정은 패키징 대상에서 제외합니다.

이미 설치된 1.0.0 앱이나 기존 바로가기는 소스 수정만으로 바뀌지 않습니다. 위젯을 완전히 종료하고 새 설치 파일을 설치한 뒤 사용합니다. 이전 바로가기의 캐시가 남으면 새로 만든 바로가기를 사용하거나 아이콘 속성에서 새 ICO를 지정할 수 있습니다. 생성한 설치 파일은 Git에 커밋하지 않고 GitHub Releases에 첨부합니다. 이번 수정 과정에서는 설치 파일 패키징·자동 테스트·커밋·push를 실행하지 않았습니다.

## 실행

Node.js와 npm이 필요합니다. 최초 `npm install`은 의존성과 Electron 실행 파일을 내려받으므로 인터넷이 필요하고, 설치 이후 기본 기능은 오프라인으로 동작합니다.

```powershell
cd "C:\Users\DYU\Desktop\종안\포폴모음\먼작귀"
npm install
npm start
```

현재 컴퓨터에서는 의존성이 설치되어 있으므로 `npm start`만 실행하면 됩니다. npm 인증서 오류가 발생하면 인증서 검증을 끄지 말고 Node의 시스템 인증서 사용을 설정한 뒤 설치합니다.

```powershell
$env:NODE_OPTIONS = (($env:NODE_OPTIONS + " --use-system-ca").Trim())
npm install
```

## 기능

- 기본 900×320 창, 이동·크기 조절, 실제 항상 위에 표시, 트레이 숨김·복원·종료.
- 실제 클릭 통과 모드. 위젯 뒤의 창을 클릭할 수 있으며 트레이의 '클릭 통과' 체크를 해제하면 복구됩니다. 설정 창은 항상 조작할 수 있습니다.
- 위젯 불투명도 40~100%, 자동/낮/노을/밤 배경 고정. 기본은 불투명도 100%와 자동 배경입니다.
- 설정 창의 내용 영역만 스크롤되고 저장·초기화 버튼과 결과 메시지는 하단에 유지됩니다. 입력창 높이와 글꼴을 통일하고, 좁은 위젯의 긴 상태 문구는 말줄임과 툴팁으로 표시합니다.
- 약 480×220 미니 모드. 도구 모음·SET·트레이에서 전환하며 기본/미니 창 크기를 따로 기억합니다.
- SET에서 걷기·점심·퇴근·소소한 행동을 20초 미리보기. 요청이 지연돼도 5초 후 처리 상태를 해제하며, 단순 비활성화 버튼에는 로딩 커서를 사용하지 않습니다. 중지하거나 설정 창을 닫으면 실제 상태로 돌아갑니다. 일정·일별 메뉴·퇴근 기록은 가상 상태로 바꾸지 않습니다.
- 기본 OFF인 휴식 알림. 점심을 제외한 누적 근무시간 기준 30/45/60/90/120분 간격으로 업무 중 8초 말풍선을 표시합니다. 숨김·절전 복귀·재실행 시 지난 알림을 몰아서 재생하지 않습니다.
- 치이카와의 짧은 손 인사, 하치와레의 친구 바라보기, 우사기의 작은 점프. 한 번에 한 캐릭터만 짧게 행동하며 SET에서 끌 수 있습니다.
- 출근·점심·퇴근·근무 요일 설정. 자정을 넘는 근무는 출근 날짜의 요일을 기준으로 하며 점심은 근무 구간 안에 있어야 합니다.
- 시스템 로컬 시각에서 상태와 남은 시간을 다시 계산하며 점심을 제외한 근무 진행률을 표시합니다.
- 날짜별 랜덤 점심 메뉴, 클릭 반응과 하트, 대기·양방향 걷기·눈 깜빡임·메뉴에 맞는 식사 동작.
- 퇴근하면 인사 말풍선을 띄우고 오른쪽에 모여 쉬며, 작은 집이나 문 안으로 사라지는 연출은 없습니다. 이미 퇴근한 뒤 켜면 인사를 반복하지 않습니다.
- 프레임별 투명 여백·크기·발 위치 보정, 고정된 상체와 이동 거리 기준의 발걸음, 충돌 시 정지와 완만한 가속·감속, 설정 창 치이카와 아이콘.
- 낮·노을·밤 배경 전환. 캐릭터 크기 조절과 기본 음소거.
- 설정·창 위치·최근 60개 근무 날짜의 메뉴와 퇴근 이벤트 기록 저장. 재실행은 퇴근 동작을 처음부터 재생하지 않습니다.
- 절전 복귀 시 현재 상태 재계산, 모니터 변경 시 창 위치 복구. 숨긴 창의 캐릭터 프레임 갱신 중지.

설정은 `%APPDATA%\MeonjakkwiWidget\settings.json`에 저장됩니다. 미니 모드는 도구 모음·트레이에서 바로 전환하거나 SET에서 저장해 적용합니다. 휴식 알림은 SET에서 체크와 간격을 선택한 뒤 저장합니다. 클릭 통과·불투명도·배경은 SET의 '화면'에서 저장해 적용합니다. 클릭 통과는 트레이에서도 바로 켜고 끌 수 있고, 저장에 실패해도 트레이에서 마우스 조작을 복구할 수 있습니다. 미리보기는 저장하지 않고 바로 재생할 수 있습니다. PIN은 상태를 유지하는 토글, HIDE는 트레이로 숨김, QUIT는 실제 종료입니다. 소리는 사용자가 켜고 창과 상호작용한 경우에만 재생합니다. 앱 최초 실행이 이미 퇴근 후라면 지난 퇴근 이벤트를 새로 재생하지 않습니다.

## 이미지와 범위

`assets/meadow-atlas.png`는 낮·노을·밤 3행, `characters-atlas-v2.png`는 캐릭터 3행×표정 6열, `food-atlas.png`는 메뉴 2행×3열입니다. 기존 `characters-atlas.png`도 보존했습니다. 캐릭터 배열은 정확한 등분이 아니므로 `renderer/widget.js`의 `spriteRows`와 `spriteColumns`에서 실제 영역을 지정하고, 투명 여백을 제외한 각 프레임을 공통 크기와 발 기준선에 맞춰 Canvas에 표시합니다. 걷기 프레임의 상체는 같은 그림을 사용하고 발 부분만 전환합니다. 오른쪽 걷기는 왼쪽 걷기 프레임을 좌우 반전합니다. 식사 프레임은 빈손이며 그날 메뉴 이미지를 합성합니다. 우사기 귀가 다른 캐릭터 영역에 섞이지 않도록 분리하고, 귀 높이를 포함한 표시 공간을 확보했습니다. 내장 이미지 생성 도구로 준비한 그림이며 공식 캐릭터 원본이나 정식 배포 자료가 아닙니다. 원본 스프라이트를 제공하면 이 파일과 표시 좌표를 교체할 수 있습니다. 캐릭터·이미지의 외부 배포나 상업적 사용 권한을 제공하는 프로젝트는 아닙니다.

이미지 생성 지시: 같은 정원의 낮·노을·밤을 동일한 구도로 3행 배치, 치이카와·하치와레·우사기를 대기/걷기2개/눈감기/반응/식사 순서의 투명 6×3 스프라이트로 배치, 점심 음식 6개를 투명 3×2 배열로 배치. 모든 최종 이미지는 프로젝트 내부에 복사했습니다.

추가 이미지 생성 지시(내장 도구): 기존 캐릭터 정체성을 유지하면서 빈손 식사·왼쪽 걷기 2프레임·일관된 비율의 6×3 투명 배열로 수정했습니다.

UI는 로컬 HTML/CSS/JavaScript이고 메인 프로세스만 창·설정 파일을 제어합니다. `contextIsolation`, `sandbox`를 사용하고 `nodeIntegration`을 끕니다. IPC 요청 창·프레임·입력을 검사하고 원격 리소스와 외부 창 열기를 차단합니다. Canvas 보정용 이미지는 고정된 두 PNG 파일만 IPC로 전달하며 임의 경로 읽기 API는 없습니다. 로그인·서버·광고·자동 실행 등록은 없습니다.

빌드·자동 테스트·설치파일 패키징·Git 커밋·push는 실행하지 않았습니다. 생성 이미지에 프레임 간 미세한 차이가 있을 수 있으며, 실제 Windows 조작과 다양한 배율·절전·모니터 전환은 별도 수동 확인이 필요합니다.
