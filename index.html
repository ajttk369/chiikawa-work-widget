설치하고 실행하기

  1. 설치 파일 받기

    위의 Windows 다운로드 버튼으로 최신 .exe 파일 하나만 받아요.

  2. 설치하기

    받은 파일을 더블클릭하고 설치를 완료해요.

  3. 열고 친구 고르기

    바탕화면 아이콘이나 시작 메뉴의 먼작귀로 실행해요. 설정의 함께할 친구에서 원하는 친구 1~3명을 고르고 저장해요.

바탕화면에 아이콘 두기

  1. 시작 메뉴에서 먼작귀를 검색해요.
  2. 앱을 우클릭하고 파일 위치 열기를 선택해요.
  3. 열린 폴더의 먼작귀 아이콘을 우클릭한 뒤 추가 옵션 표시 → 보내기 → 바탕 화면에 바로 가기 만들기를 선택해요.

새 버전 업데이트

앱이 새 버전을 확인하면 알려줘요. 다운로드 → 재시작하고 적용을 선택하면 업데이트돼요. 트레이 아이콘을 우클릭해 업데이트 확인을 누를 수도 있어요.

업데이트 확인과 다운로드에는 인터넷 연결이 필요해요. 업무시간과 캐릭터 설정은 그대로 유지돼요.
