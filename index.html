설치하고 실행하기

  1. 설치 파일 받기

    위의 Windows 다운로드 버튼으로 .exe 파일을 받아요.

  2. 설치하기

    받은 파일을 더블클릭하고 설치를 완료해요.

  3. 위젯 열기

    바탕화면 아이콘을 더블클릭해요. 아이콘이 없으면 시작 메뉴에서 먼작귀를 검색해 실행해요.

바탕화면에 아이콘 두기

  1. 시작 메뉴에서 먼작귀를 검색해요.
  2. 앱을 우클릭하고 파일 위치 열기를 선택해요.
  3. 열린 폴더의 먼작귀 아이콘을 우클릭한 뒤 추가 옵션 표시 → 보내기 → 바탕 화면에 바로 가기 만들기를 선택해요.
